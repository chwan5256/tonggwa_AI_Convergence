# PASCO → 시트 실시간 브리지 (최소 시험판)

교사 PC 한 대에서 무선 날씨센서(PS-3209)를 읽어 Apps Script 웹앱으로 보냅니다.
학생은 SPARKvue 없이도 웹앱 '실시간 패널'에서 값을 봅니다.

## 준비 (한 번)
1. **Python 설치**: python.org에서 Windows용 Python 설치. 설치 첫 화면에서 **“Add python.exe to PATH”를 반드시 체크**.
   - PASCO 라이브러리 0.3.65는 3.11 이상, PyPI 최신 0.3.66은 3.14 이상으로 표기 → 새로 설치한다면 **3.14** 권장
2. 명령 프롬프트(cmd)에서 `pip install pasco`
3. PC 블루투스 켜기(데스크톱은 PS-3500 어댑터가 필요할 수 있음)
4. 구글 시트 만들기 → 확장 프로그램 › Apps Script → `apps-script/Code.gs` 내용 붙여넣기 → `setup()` 실행(권한 허용) → 실행 로그의 **WRITE_TOKEN** 메모 → 배포 › 새 배포 › 웹 앱(실행: 나 / 액세스: 모든 사용자) → **/exec 주소** 메모
5. `bridge/run_bridge.bat` 더블클릭 → 처음엔 `config.bat`이 메모장으로 열림 → 센서 ID(센서 뒷면 6자리), /exec 주소, 토큰을 채우고 저장
   - `config.bat`은 `.gitignore`로 **저장소에 올라가지 않습니다**(공개 저장소에 토큰 노출 방지)

## 연결 시험 (run_bridge.bat 메뉴 번호 순서대로)

| 순서 | 메뉴 | 성공 기준 | 안 될 때 |
|---|---|---|---|
| ① | **3** 시트 연결만 | `live` 시트에 `TEST(가짜값)` 3행, 화면에 latest 출력 | 주소가 /exec로 끝나는지, 토큰 오타, 배포 액세스 ‘모든 사용자’ |
| ② | **1** 센서 목록 | 날씨센서 이름과 측정 항목(Temperature, RelativeHumidity, BarometricPressure, WindSpeed …)이 나옴 | 센서 전원(초록 불 깜박임), **SPARKvue에서 연결 끊기**, PC 블루투스 |
| ③ | **2** 읽기만 | 30초마다 기온·습도·기압(hPa, 1000 안팎)이 찍히고 `backup/live_backup.csv`에 쌓임 | 기압이 100 안팎이면 단위 문제 → 알려 주세요 |
| ④ | **4** 실시간 전송 | 1분마다 “시트 n행 저장”, 교사용 페이지 ④에서 최신 기록 시각이 바뀜 | ①이 됐는데 ④가 안 되면 토큰 확인 |
| ⑤ | 로깅과 함께 | **로깅 모드로 기록 중인 센서**에 ②·③을 다시 해 봄 | 연결이 안 되면: 수업 시작 전 SPARKvue로 로깅을 끝내 동기화하고 브리지로 넘김 |

①이 끝나면 `live` 시트의 TEST 행은 지우세요.

## 알아 둘 것
- 센서 1개는 기기 1대에만 연결됩니다. 브리지를 돌릴 때는 SPARKvue(크롬북·PC)에서 날씨센서 연결을 끊어 둡니다.
- 기압은 **hPa로 바꿔서** 보냅니다(라이브러리 기본 kPa, SPARKvue 내보내기 기본 mmHg). 풍속은 m/s.
- 풍향은 센서 내장 나침반으로 늘 값이 나오지만 날개(PS-3553)가 바람을 받을 때만 의미가 있습니다. 풍속이 0.3 m/s 미만이면 웹앱이 정온으로 처리합니다. 자기 북 기준이라(서울 편각 약 −8°) 16방위 경계 근처는 한 칸 어긋날 수 있습니다.
- PC 절전 모드를 끄세요. 밤새 기록은 센서 **로깅 모드**가 더 안전합니다(브리지는 수업 시간 실시간용).
- 센서는 **실외 그늘·통풍되는 곳**에 둡니다. 실내 창가·햇빛 아래 값은 기상청 관측 조건(백엽상, 10 m 풍속)과 달라 AI 입력값으로 쓰기 어렵습니다.
- 브리지가 끝내 안 되면: 브리지를 끄고 SPARKvue로 센서를 연결해 데이터 스트리밍 → 학생은 값을 웹앱 06에 직접 입력합니다.
