# 통합과학2 Ⅲ. 과학과 미래 사회 · AI 융합수업 — AI 예보관

통합과학2 Ⅲ. 과학과 미래 사회 · AI 융합수업(데이터 분석형) 웹앱
`[10통과2-03-02]` `[10통과2-03-03]` `[10통과2-03-04]`

날씨 속담을 과학 원리로 가설로 바꾸고, 기상청 ASOS 서울 10년 시간자료로 검증하고,
의사결정트리 AI 예보관을 학습시켜 규칙 예보관과 겨룬 뒤, 우리 학교 PASCO 무선 날씨센서의
실측값으로 실제 예보를 냅니다. 교사가 바이브코딩으로 제작했습니다.

## 파일
| 경로 | 내용 |
|---|---|
| `index.html` | 학생 화면(1차시 관측소 · 2차시 본차시 · 3차시 채점·한계 · 4차시 SSI 대시보드) |
| `config.js` | 설정 한 곳: Apps Script 주소, 구글 로그인 클라이언트 ID, 예비 계정·비밀번호 지문, 반 목록 |
| `teacher.html` | 교사용(허용 구글 계정 + 비밀번호 입장): ASOS 원자료 변환기 · 연결 정보 · 실제 날씨 입력 · 브리지 상태 |
| `core.js` | 계산 핵심(가설 교차표 · 의사결정트리 · 평가 · SPARKvue CSV 해석) — 화면과 시험이 같은 함수 사용 |
| `data/asos_108_hourly.csv` | 기상 빅데이터(교사가 변환해 넣음 · 아직 없음) |
| `apps-script/Code.gs` | 시트 백엔드(실시간 센서값·모둠 관측·예보 카드·실제 날씨) |
| `bridge/` | PASCO 날씨센서 → 시트 Python 브리지, 연결 시험 스크립트, `run_bridge.bat` 시험 메뉴 |
| `docs/DESIGN.md` | 설계서(화면 · 데이터 명세 · 파이프라인 · 캐싱 · 검증) |

## 처음 한 번
1. 기상자료개방포털에서 서울(108) 시간자료를 한 해씩 CSV로 받아 `teacher.html` ①에 끌어다 놓기 → `data/asos_108_hourly.csv`로 넣고 커밋 (`data/README.md`)
2. 구글 시트 → 확장 프로그램 › Apps Script에 `apps-script/Code.gs` 붙여넣기 → **편집기에서만** `SETUP_PIN`에 교사 비밀번호 입력 → `setup` 실행(권한 허용) → `SETUP_PIN`을 다시 빈칸으로 → 웹 앱 배포(실행: 나 / 액세스: 모든 사용자) → /exec 주소를 `config.js`의 `GAS`에 넣고 커밋
   - 비밀번호는 저장소 어디에도 적지 않습니다. 바꾸려면 `SETUP_PIN`에 새 값을 넣고 `설정초기화` 실행
   - 코드를 고친 뒤에는 배포 관리 › ✏ 편집 › 버전: 새 버전(주소 유지)
3. `bridge/run_bridge.bat` 메뉴로 센서 브리지 시험(`bridge/README.md`)

토큰·센서 기록은 `.gitignore`로 저장소에 올라가지 않습니다(공개 저장소).

## 주소 옵션
- `?gas=<Apps Script exec 주소>` 실시간 연결(한 번 열면 기기에 저장)
- `?h=6|12|24` 예보 시간 범위(기본 6시간)
- `?tab=l1|l2|l3|l4` 처음 열 차시
- `?form=<구글 설문 주소>` 출구 카드 버튼
