# AI 예보관 — 속담 vs 빅데이터 vs AI

통합과학2 Ⅲ. 과학과 미래 사회 · AI 융합수업(데이터 분석형) 웹앱
`[10통과2-03-02]` `[10통과2-03-03]` `[10통과2-03-04]`

날씨 속담을 과학 원리로 가설로 바꾸고, 기상청 ASOS 서울 10년 시간자료로 검증하고,
의사결정트리 AI 예보관을 학습시켜 규칙 예보관과 겨룬 뒤, 우리 학교 PASCO 무선 날씨센서의
실측값으로 실제 예보를 냅니다. 교사가 바이브코딩으로 제작했습니다.

## 파일
| 경로 | 내용 |
|---|---|
| `index.html` | 학생 화면(1차시 관측소 · 2차시 본차시 · 3차시 채점·한계) |
| `teacher.html` | 교사용: ASOS 원자료 변환기 · 실시간 연결 설정 · 실제 날씨 입력 |
| `core.js` | 계산 핵심(가설 교차표 · 의사결정트리 · 평가 · SPARKvue CSV 해석) — 화면과 시험이 같은 함수 사용 |
| `data/asos_108_hourly.csv` | 기상 빅데이터(교사가 변환해 넣음 · 아직 없음) |
| `apps-script/Code.gs` | 시트 백엔드(실시간 센서값·모둠 관측·예보 카드·실제 날씨) |
| `bridge/` | PASCO 날씨센서 → 시트 Python 브리지, 연결 시험 스크립트, `run_bridge.bat` 시험 메뉴 |
| `docs/DESIGN.md` | 설계서(화면 · 데이터 명세 · 파이프라인 · 캐싱 · 검증) |

2. 구글 시트 + `apps-script/Code.gs` 배포 → `teacher.html` ②에 주소·토큰 저장 → 학생용 링크 복사
3. `bridge/run_bridge.bat` 메뉴로 센서 브리지 시험(`bridge/README.md`)

토큰·센서 기록은 `.gitignore`로 저장소에 올라가지 않습니다(공개 저장소).
