# data/ — 기상 빅데이터

이 폴더에 `asos_108_hourly.csv`를 넣으면 학생 웹앱이 자동으로 읽습니다.
**아직 파일이 없습니다.** 교사용 페이지(`teacher.html`) ①에서 만들어 넣으세요.

## 받는 순서(기상자료개방포털)
1. https://data.kma.go.kr 로그인
2. 데이터 › 기상관측 › 지상 › 종관기상관측(ASOS) › 자료
3. 자료형태 **시간 자료**(파일 이름에 `_HR_`, ⚠ `_DAY_` 일자료는 쓸 수 없음) · 지점 **서울(108)** · 요소 **기온, 강수, 바람, 기압, 습도**
4. 시간 자료는 **1회 최대 1년** → 2016년부터 2025년까지 한 해씩 조회해 **CSV** 10개 내려받기(또는 ‘파일셋’ ZIP)
5. `teacher.html` ①의 상자에 10개를 한꺼번에 끌어다 놓기 → 연도별 표 확인 → `asos_108_hourly.csv` 내려받기 → 이 폴더에 넣고 커밋

- 형식: `t,ta,rh,p,ws,wd,rn` (시각 KST · 기온 °C · 습도 % · 현지기압 hPa · 풍속 m/s · 풍향 ° · 강수량 mm), 약 3~4 MB
- 합성·가공 데이터를 넣지 않습니다. 반드시 기상청 원자료를 변환한 파일만 둡니다.
